# zynqo-spring-boot-starter

This artifact contains no code. It aggregates the dependencies needed to use Zynqo in a
Spring Boot MVC application:

- `zynqo-spring-boot-autoconfigure`
- `zynqo-storage-redis`
- `spring-boot-starter-data-redis`

API documentation is published with `zynqo-core`, `zynqo-storage-redis` and
`zynqo-spring-boot-autoconfigure`. See https://github.com/tanmaysinghx/zynqo-spring-boot-starter
