# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. All participants in issues, pull requests, discussions and other project
spaces are expected to follow it.

## Our standards, in short

- Be respectful and constructive, and assume good intent.
- Critique ideas and code, not people.
- No harassment, discrimination, personal attacks or publishing others' private information.

## Enforcement

Report unacceptable behaviour privately to the maintainer through GitHub
(<https://github.com/tanmaysinghx>) or by a private security advisory if the matter is sensitive.
Reports are handled confidentially. Maintainers may remove contributions and restrict
participation in line with the Contributor Covenant's enforcement guidelines.
